# ⚔️ جنگ جهانی ۳ — ربات تلگرام (دو ربات جدا)

سیستم کامل بازی «جنگ جهانی» با **دو ربات جداگانه** و یک دیتابیس مشترک:

| ربات | توضیح |
|---|---|
| 🎮 **ربات اصلی** (`run_game.py`) | بازی بازیکن‌ها: عضویت، انتخاب کشور، امپراطوری، جنگ، سازمان ملل، سکه شاهی و... |
| 🛡 **ربات ادمین** (`run_admin.py`) | پنل مدیریت با دسترسی **صددرصدی به همه چیز**: ساخت، ویرایش و حذف هر داده بازی |

---

## ⚡️ راه‌اندازی (۵ دقیقه)

### ۱) توکن ربات‌ها (از قبل ثبت شده) ✅
توکن‌ها و آیدی ادمین کل از قبل داخل کد هستند و **نیازی به ساخت ربات جدید یا فایل `.env` نیست**:

| ربات | توکن |
|---|---|
| 🎮 ربات بازی | `9201202722:AAGuSaJQw16F_ugrKXUidttYfMqI9Cz3SVE` |
| 🛡 ربات ادمین | `9000162449:AAG-xoIDUSgE1LFWr1L3BOZjygueYuCZOfU` |
| 👑 آیدی ادمین کل | `8666501866` |

این مقادیر در `core/config.py` (`DEFAULT_GAME_BOT_TOKEN`، `DEFAULT_ADMIN_BOT_TOKEN`،
`DEFAULT_ADMIN_ID`) ثبت شده‌اند. برای تغییرشان فقط `.env.example` را به `.env`
کپی کنید یا از پنل وب (تب سکرت‌ها) استفاده کنید.

### ۲) نصب
```bash
cd worldwar-game
pip install -r requirements.txt
```
(نیازمند Python 3.10 یا بالاتر)

### ۳) تنظیمات اختیاری
اگر خواستید توکن‌ها/آیدی را از کد جدا کنید:
```bash
cp .env.example .env
```
```env
GAME_BOT_TOKEN=9201202722:AAGuSaJQw16F_ugrKXUidttYfMqI9Cz3SVE
ADMIN_BOT_TOKEN=9000162449:AAG-xoIDUSgE1LFWr1L3BOZjygueYuCZOfU
SUPER_ADMIN_ID=8666501866
```

### ۴) اجرا (کاملاً پایتونی)
```bash
# پنل فرماندهی وب + هر دو ربات در یک دستور:
python3 ../server.py          # از ریشهٔ پروژه
# یا:
python3 run_all.py            # پنل وب روی http://0.0.0.0:3000

# فقط ربات‌ها (بدون پنل وب):
python3 run_bots.py
# یا جداگانه در دو پروسه/سرور:
python3 run_game.py     # فقط ربات اصلی
python3 run_admin.py    # فقط ربات ادمین

# پنل وب به‌تنهایی:
python3 web.py --web-only
```

پنل فرماندهی: `http://SERVER_IP:3000` — وضعیت سلامت: `/health`.

دفعات اول، دیتابیس `wwgame.db` خودکار ساخته و با داده‌های اولیه پر می‌شود:
**۴۵ کشور واقعی، ۴۶ تجهیزات نظامی (۶ دسته شامل 🚀 موشکی)، ۳۸ ساختمان/پروژه، ۱۰ قانون، ۶ دین، ۶ حکومت، ۷ ماموریت روزانه، ۴ پکیج سکه**.

💡 بودجه اولیه هر بازیکن تازه‌وارد با تنظیم `initial_money` کنترل می‌شود (پیش‌فرض: **۲۰۰٬۰۰۰٬۰۰۰ = ۲۰۰ میلیون**) — از مسیر ⚙️ تنظیمات ← «💵 بودجه اولیه بازیکن جدید» هم قابل ویرایش است و در ریست بازیکنان/پول از همان مقدار استفاده می‌شود.

## 🛡 ربات ادمین — تغییر صددرصد همه چیز

پنل ادمین با `/start` یا `/panel` باز می‌شود:

- 👥 **کاربران**: جستجو، سکه/پول ±، بن، برداشتن کشور، حذف پژوهش‌ها/تجهیزات، ریست کامل، پیام خصوصی
- 🪙 **اقتصاد**: قیمت هر سکه (مثلاً ۳۴ میلیون تومان)، کارت به کارت، نرخ تبدیل، فیش‌ها، پکیج‌ها، بازار
- 🧾 **فیش‌ها**: دکمه اختصاصی «🧾 فیش‌های در انتظار» در پنل اصلی + دکمه‌های ✅/❌ روی هر ردیف لیست (بدون نیاز به باز کردن فیش) + تأیید/رد سریع با دستور `/approve 12` و `/reject 12`؛ با تأیید، کشور/سکه خودکار به بازیکن می‌رسد + اطلاع‌رسانی
- 🏳 **کشورها**: نام، پرچم، ویژه/رایگان، قیمت سکه و تومان، جمعیت، دریا، منطقه — همه قابل ویرایش
- 🪖 **نظامی**: تجهیزات (قدرت حمله/دفاع/سرعت/قیمت)، دسته‌ها، سربازها، پایگاه‌ها
- 🚀 **دسته جدید «موشکی»** با ۷ موشک آماده (کروز، بالستیک، ضدکشتی، پدافند) — هر تجهیز جدیدی که ادمین بسازد هم در فروشگاه پادگان دیده می‌شود
- 🌍 **دنیا**: ساختمان‌ها، قوانین (با اثر ادیان/حکومت‌ها)، ادیان، حکومت‌ها
- 🏢 **شرکت‌ها و پروژه‌ها**: انواع شرکت، شرکت‌های بازیکن‌ها، پژوهش‌ها (قابل حذف تک‌تک)
- 🗳 **سازمان ملل و جنگ‌ها**: رای‌گیری‌ها، آرا، جنگ‌ها، نبردها، عملیات سایبری، بیانیه‌ها
- 🎯 **ماموریت‌ها**: ساخت/ویرایش ماموریت روزانه با هر پاداشی
- 🎫 **پشتیبانی**: تیکت‌ها با پاسخ مستقیم به بازیکن
- ⚙️ **تنظیمات**: همه کلیدها + متن راهنمای بازی + متن استارت
- 📣 **پیام همگانی** به همه بازیکن‌ها
- 🛡 **ادمین‌ها** (سوپرادمین): افزودن ادمین با ۱۳ دسترسی تفکیک‌شده
- 🗄 **دیتابیس خام**: مرور مستقیم **۳۲ جدول** — حتی جدول‌هایی که منوی اختصاصی ندارند
- 📜 **لاگ‌ها**: ثبت همه عملیات ادمین‌ها

دستورهای سریع: `/panel` `/stats` `/u` `/receipts` `/tickets` `/settings` `/bc` `/logs`

## 🎮 امکانات ربات اصلی (خلاصه)

- **عضویت اجباری** در کانال/گروه + دکمه بررسی
- **انتخاب کشور**: ۱۵ کشور رایگان + ۳۰ کشور ویژه (خرید با 🪙 سکه شاهی یا 💳 فیش کارت به کارت)
- **منو شروع** با ۶ دکمه: امپراطوری من / ماموریت روزانه / سکه شاهی / راهنمای بازی / پشتیبانی / تغییر کشور (قانون ۸ ساعت)
- **امپراطوری من**: مدیریت کشور، اتاق جنگ، تجارت بین‌المللی، سازمان ملل، بیانیه، درآمد روزانه
- **مدیریت کشور**:
  - 👥 مردم: برق/آب/گاز (نیروگاه‌ها + قطعی ۱-۲۴ ساعته)، غذا و بهداشت (گرسنگی، خرید به تن)، رفاه (پول+رتبه ارز، یارانه، مالیات، قوانین)، مسکن
  - 🏗 پروژه ملی: تفریحی (برج با نام و ارتفاع دلخواه، ورزشگاه‌ها...)، علمی (ویروس، واکسن، غنی‌سازی، ماه، هوش مصنوعی، شهر فضایی، موجود)، احداث شرکت (۶ نوع با نام دلخواه + اعلام در کانال)
  - 🪖 ارتش: پایگاه نظامی (درخواست/تأیید بین کشورها)، پادگان (خرید ۲۴ تجهیز در ۵ دسته + تعلیم سرباز ۱-۵٪ جمعیت)
  - ⛪ دین و حکومت (۶ دین × ۶ حکومت با اثر متفاوت + تغییر پرچم)
- **اتاق جنگ**: اعلان جنگ با/بدون مجوز (رای‌گیری ۳۰ دقیقه‌ای سازمان ملل)، **۶ نوع حمله**: دریایی/هوایی/زمینی/موشکی/فضایی/ترکیبی با قواعد جغرافیایی، سایبری (ترور رهبر/دزدی خزانه/تداخل سرور — قدرت برابر ۵۰٪، دو برابر ۹۵٪، نصف ۲۵٪)
  - ⏳ **رای‌گیری مجوز جنگ ۳۰ دقیقه** است (تنظیم `war_vote_minutes`) و به‌طور خودکار توسط زمان‌بند بسته می‌شود؛ اگر هیچ کشوری رأی ندهد مجوز خودکار صادر می‌شود تا جنگ معطل نماند.
  - 🚀 **حمله موشکی** از هر فاصله‌ای با موشک کروز/بالستیک/ضدکشتی و راکت‌انداز ممکن است (+۱۵٪ ضربه غافلگیرکننده) و با پدافند هوایی مدافع رهگیری می‌شود.
  - 🪖 حمله زمینی با سرباز تنها (بدون تجهیزات) هم انجام می‌شود؛ اگر نوع حمله‌ای ممکن نباشد دلیلش دقیق نمایش داده می‌شود.
- **سازمان ملل**: رای‌گیری با وزن ۲ برای قدرت‌ها، گزارش و تحریم (خلع سلاح/لغو تجارت/برکناری رهبر با سکه)
- **سکه شاهی**: خرید سفارشی + پکیج + فیش + تبدیل به پول پایه
- **ماموریت روزانه** با ۷ ماموریت seed شده (ادمین می‌تواند هر تعداد اضافه کند)

### 🆕 آپدیت بزرگ (نسخه ۲)

- 🔥 **اتصال به سرور به شکل فایربیس**: با پر کردن `FIREBASE_DB_URL` و `FIREBASE_AUTH` در `.env`، بازی به Firebase Realtime Database شما وصل می‌شود (REST + heartbeat + صف همگام‌سازی + اسنپ‌شات دوره‌ای)؛ وضعیت اتصال در منو شروع و پنل ادمین نمایش داده می‌شود. بدون تنظیم، بازی در «حالت محلی» (JSON پشتیبان) ادامه می‌دهد.
- 💰 **درآمد خودکار هر ۳۰ دقیقه**: مالیات هر کشور + کسر یارانه + عوارض تنگه‌ها + استخراج نفت + انبار مازاد برق/آب/گاز؛ به هر بازیکن پیام خصوصی داده می‌شود (زیر همه پیام‌ها دکمه «🏰 بازگشت به امپراطوری من» هست).
- 🤝 **تجارت بین‌المللی بازسازی شد**:
  - 🕊 **مذاکره مخفیانه** با اعلام شروع در کانال (با عکس ادمین) + عضو کردن کشور سوم (عکس مذاکره سه‌نفره) + دکمه‌های «به نتیجه رسیدیم/نرسیدم» زیر پیام‌های طرف مقابل.
  - 📜 **۵ پیمان**: نظامی (دفاع مشترک ۳۰٪)، رفیقای تجاری (درصدی از فروش + سازوکار خیانت و شکستن قرارداد با کاهش دیپلماسی و اعلام در کانال)، صلح (پایان جنگ فعال)، اعتماد (دیدن آنی اطلاعات کامل از دکمه «اعتماد (x)» با شاهد سوم در سازمان ملل)، برادران تنی (هرکدام/همه یکجا). همه با عکس سوپرادمین و جمله «این قرارداد توسط کشور X و کشور Y و کشور شاهد T انجام شد».
  - 🔁 **تجارت مستقیم**: معاوضه نیرو/انرژی/پول/تجهیزات/سکه شاهی/نفت بین دو کشور (بدون اعلام کانال).
  - 🏥 **فروش انرژی به سازمان نجات**: برق/آب/گاز/نفت → پول + حمایت (اعلام کانال با عکس، بدون مبلغ).
  - ⚓ **تنگه‌ها**: ۸ تنگه واقعی؛ تصاحب با نبرد دریایی **فرسایشی** (تنگه آزاد حداقل ۵۰۰ قدرت دریایی؛ تنگه دارای مالک با تأیید بازیکن و بدون بلاک)؛ مالک ۱.۵٪ درآمد غیرمالیاتی کشورهای دریایی می‌گیرد؛ خاموش/روشن تکی و کلی از ربات ادمین.
- 🛟 **سازمان نجات در امپراطوری من**: برای هر جنگ یک بخش مجزا؛ رأی با اهدای انرژی؛ اکثریت → ۱۰٪ ذخیره مخفی؛ نتیجه در کانال با عکس.
- 🛢 **بخش نفت در مردم**: مخزن زیرزمینی + نفت‌خیزی هر کشور (قابل ویرایش ادمین)، دکل، استخراج خودکار، اکتشاف با شانس، فروش نفت به پول یا سکه.
- 💵 **مدل ارز جدید**: هر کشور ارز خودش (ریال/دلار/...)؛ امتیاز = تجارت ۲۴ ساعت + خزانه + نظامی + رضایت؛ ارز مشترک = میانگین گروه؛ قوی‌ترین ارز «پول اصلی بازی» می‌شود (اعلام کانال با عکس)؛ تغییر/ساخت ارز با تأیید ادمین.
- 🛡 **ربات ادمین جدید**: گزارش روزانه ۲۴ ساعت اخیر (ساعت قابل تنظیم + /daily)، 🖼 کتابخانه تصاویر دائمی با اسم برای هر بخش، تغییر قیمت کشور‌ها/سکه شاهی/نرخ تبدیل، 🎬 مدیریت سیزن (ساخت/تغییر اسم/تغییر مود/حذف + رای‌گیری کانال با حد رأی)، ساخت جمعی تجهیزات (اسم-سرعت-حمله-دفاع-قیمت)، تأیید درخواست‌های ارز، 🔘 خاموش/روشن کردن هر بخش.

- **پیام همگانی/پاسخ تیکت چطور به بازیکن می‌رسد؟** ربات ادمین با توکن ربات اصلی به بازیکن پیام می‌دهد؛ پس بازیکن باید حداقل یک بار ربات اصلی را استارت کرده باشد.
- **اعلان کانال**: ربات اصلی را در کانال اعلانات ادمین کنید تا خبر احداث/جنگ/بیانیه ارسال شود.
- **دو پروسه جدا روی دو سرور**: دیتابیس SQLite با WAL روی هر دو اجرا همزمان کار می‌کند؛ فقط فایل `wwgame.db` باید بین دو سرور مشترک باشد (یا هر دو را با `run_all.py` روی یک سرور اجرا کنید).
- **هاست پیشنهادی**: هر VPS لینوکس ارزان یا هاست پایتون با اجرای دائمی (`systemd` / `screen` / `tmux`).
- FSM حافظه‌ای است؛ با ری‌استارت، عملیات نیمه‌کاره (مثل ارسال فیش در همان لحظه) لغو می‌شود ولی داده‌ها سالم می‌مانند.

هر نوشتن مهم به مسیر `game/...` میرور می‌شود + هر ۵ دقیقه اسنپ‌شات کامل جداول + heartbeat هر دقیقه.

### 🆕 آپدیت (پرچم، عکس اعلان‌ها، سایبری، اهداف جنگ، مالیات میلیونی)

- 🏳 **پرچم انتخابی ثابت می‌ماند**: پرچمی که بازیکن از گالری ادمین انتخاب می‌کند (یا ادمین به کشور انتساب می‌دهد) دیگر با راه‌اندازی مجدد ربات به پرچم FlagCDN بازنویسی نمی‌شود؛ بعد از انتخاب هم همان لحظه به‌صورت عکس نمایش داده می‌شود.
- 🖼 **عکس‌های ادمین روی همه اعلان‌ها**: بخش‌های جدید کتابخانه تصاویر (`⚔️ اعلان جنگ`، `💥 حمله و گزارش نبرد`، `🗳 سازمان ملل`، `🕶 سایبری`، `🏗 پروژه`، `🏛 حکومت`، `🏕 پایگاه`، `💰 مالیات`، `📢 بیانیه`، `🎬 سیزن`، `📦 عمومی`) به‌کار رفتند؛ همه اعلان‌های کانال از `announce(section=...)` رد می‌شوند، اگر عکس بخش نبود عکس «عمومی» و در نهایت فقط متن ارسال می‌شود.
- 🕶 **عملیات سایبری درست کار می‌کند**: باگ پارس callback که باعث می‌شد هیچ عملیاتی اجرا نشود رفع شد و فرمول شانس بازطراحی شد (قدرت برابر = ۵۰٪).
- 🎯 **لیست اهداف جنگ/سایبری/سازمان ملل/پایگاه** بر اساس «کشور ثبت‌شده روی کاربر» ساخته می‌شود، نه فقط `countries.owner_id`؛ کشورهایی مثل روسیه و ژاپن که owner_id آن‌ها خالی مانده بود حالا در لیست هستند و حمله به آن‌ها ممکن است. تابع `sync_country_owners()` هنگام هر راه‌اندازی مالکیت‌های دوگانه/ناقص را هم اصلاح می‌کند.
- 💰 **مالیات میلیونی و وابسته به جمعیت و رضایت**: درآمد روزانه = (جمعیت ÷ ۱۰۰۰) × ضریب درآمد × (۰٫۵ + رضایت÷۱۰۰) × (۱ + نرخ مالیات)؛ همه مبالغ در کل بازی با فرمت «۱۲٫۵ میلیون / ۱٫۲ میلیارد» نمایش داده می‌شوند و پیام دوره‌ای هم درآمد دوره و هم درآمد روزانه را نشان می‌دهد.

### 🏛 رهبری، ترور رئیس‌جمهور و انقلاب

- هر کشور یک **رهبر** دارد: `countries.leader_title` + `leader_name` (رئیس‌جمهور / نخست‌وزیر / پادشاه / شورا). نام‌ها شخصیت‌های داستانی بازی‌اند و از پنل ادمین (بخش «کشورها») قابل تغییرند؛ فهرست کامل در `core/seed.py → LEADERS`.
- **🎯 ترور رئیس‌جمهور** (اتاق جنگ → 🕶 سایبری): شانس بر پایهٔ قدرت سایبری، کول‌داون ۶ ساعته. ترور موفق = رهبر کشته می‌شود + کشور وارد **انقلاب** می‌شود.
- **انقلاب** (`core/politics.py`): شدت اولیه ۶۵٪، مهلت ۳۰ دقیقه، درآمد کشور تا پایان بحران ۵۵٪، رضایت −۸. سه راه مهار:
  1. **🗳 انتخابات فوری** — سه نامزد (اقتصاددان/سرلشکر/مردمی) با اثر فوری متفاوت؛ رهبر جدید ثبت و انقلاب خاتمه می‌یابد.
  2. **💸 پول‌پاشی** — هر پرداخت (شدت × ۱٬۲ میلیون) شدت را ۳۰ واحد کم می‌کند و رضایت را بالا می‌برد.
  3. **🎖 سرکوب نظامی** — شانس بر اساس ارتش، با تلفات واقعی سرباز؛ شکست شدت را بالا می‌برد.
- اگر مهلت تمام شود: انقلاب پیروز می‌شود → رضایت −۲۰، غارت ۱۵٪ خزانه و روی کار آمدن «شورای انقلابی» (سپس انتخابات آزاد است).
- مسیر کاربر: `🏛 مدیریت کشور → 🏛 رهبری و انقلاب` (`g|pol`)، به‌همراه `g|pol_elec`، `g|pol_money`، `g|pol_force`، `g|pol_leaders`.
- تیک زمان‌بند: `core.politics.revolution_tick` هر ۶۰ ثانیه در `_slow_loop` اجرا می‌شود.

### 🛢 نفت: استخراج، ارتقای تجهیزات و تجارت خودکار

- ساختمان **«دکل نفتی»** (سECTOR `oil`) در بازی اضافه شد؛ استخراج در همان تیک درآمد (۵ دقیقه) انجام می‌شود.
- **ارتقای تجهیزات استخراج** (`oil_business.level`، ۱ تا ۱۲): هر سطح +۱۵٪ استخراج و +۱۲٪ درآمد فروش؛ هزینه = `oil_level_base_cost × 1.6^(level-1)` یعنی هر مرحله **گران‌تر** (۳۰ → ۴۸ → ۷۶.۸ → ۱۲۲.۹ میلیون …).
- **🛠 ارتقا بدون نیاز به دکل:** ارتقای تجهیزات همیشه ممکن است (حتی با صفر دکل)؛ هر سطح +۱۵٪ استخراج
  و +۱۲٪ درآمد فروش. صفحهٔ `g|oilup` قبلاً به‌خاطر یک باگ (پاس‌دادن tuple به `edit_text`) باز نمی‌شد — رفع شد.

  و همین باعث می‌شد ۵۰٬۰۰۰ بشکه استخراج‌شده فقط ۵٬۰۰۰ بشکه فروش برود).

  همیشه حداقل **۱ میلیون**؛ ایران با ۵ دکل و ۵۰٬۰۰۰ بشکه ≈ **۶۹ میلیون** در هر فروش.

  `income_oil_floor_m` (۱۲ میلیون) است تا هیچ کشوری درآمد نفتی ریز نگیرد؛ با دکل و سطح تجهیزات رشد می‌کند:

### ⚔️ نبرد واقعی (Real Combat)

همهٔ حمله‌ها در `core/combat.py` حل می‌شوند — نه با درصد ثابت، بلکه با **نیروهای واقعی دو طرف**:

- **توان** از تجهیزات و سربازهای موجود دو کشور محاسبه می‌شود (پدافند هوایی موشک‌ها را رهگیری می‌کند، پیمان نظامی به دفاع کمک می‌کند).
- **استراتژی حمله** از ترکیب نیروهای اعزامی انتخاب می‌شود: یورش ناوگان سطحی، محاصره دریایی، عملیات آبی‌خاکی، کمین زیردریایی، یورش زرهی، برتری هوایی، ضربه موشکی، ضربه فضایی و عملیات مشترک. هر استراتژی ضریب توان و ضریب تلفات خودش را دارد.
- **نتیجه** بر اساس نسبت توان تعیین می‌شود: توان برابر ≈ ۵۰٪، سه برابر ≈ ۸۲٪، یک‌سوم ≈ ۱۶٪ (بین ۵٪ تا ۹۵٪).
- **هر دو طرف تلفات واقعی می‌دهند** (کسر از `player_assets`): تجهیزات و سرباز. برنده کمتر، بازنده بیشتر؛ هرچه نبرد نزدیک‌تر، خونین‌تر.
- **گزارش کانال** شامل: نوع استراتژی و توضیح آن، توان مهاجم/مدافع، شانس، نتیجه و بخش «خسارات طرفین» با فهرست دقیق تلفات هر دو کشور است.

#### ⚓ تسخیر تنگه = نبرد دریایی

`g|strait` → روی تنگه بزنید. تسخیر دیگر با «چک کردن یک عدد» انجام نمی‌شود:

1. توان دفاع دریایی مالک = ناوگان او + ۲۵٪ پدافند ساحلی (زمینی/هوایی/پدافند).
2. **حمله هرگز با «قدرت کافی نیست» بلاک نمی‌شود.** اول صفحهٔ تأیید («آیا مطمئن از حمله هستید؟») با
   قدرت دریایی شما، توان دفاع مدافع، قدرت لازم برای تصرف و شانس تصرف نشان داده می‌شود؛ با زدن
   «⚔️ بله، حمله کن» نبرد اجرا می‌شود. تنها شرط باقی‌مانده `strait_min_naval` = ۵۰۰ (حداقل ناوگان) و
   داشتن مرز دریایی است.
3. **نبرد فرسایشی (attrition):** حتی اگر این حمله تنگه را نگیرد، دست‌کم
   `strait_attrition_percent` (پیش‌فرض ۱۸٪) از ناوگان و پدافند مدافع از بین می‌رود و مهاجم هم
   `strait_attrition_min_attacker` (پیش‌فرض ۵٪) تلفات می‌دهد. با حمله‌های پشت‌سرهم دفاع مدافع می‌شکند و
   بار بعد تصرف ممکن می‌شود (`attack_outlook()` تعداد حملهٔ لازم را پیش‌بینی می‌کند).
4. `strait_capture_ratio` (پیش‌فرض ۱.۳) فقط برای «تصرف در همین یک حمله» است، نه برای شروع حمله.
5. با پیروزی، مالکیت تنگه منتقل می‌شود (و ۵٪ رضایت مدافع کم می‌شود). با شکست، تنگه دست مالک می‌ماند،
   دفاع او **کم شده** (قبل → بعد در گزارش) و ۳٪ رضایت مهاجم کم می‌شود.
6. گزارش کامل در کانال (بخش عکس «⚓ تنگه‌ها») و به مدافع در پیام خصوصی ارسال می‌شود.

| مسیر | کار |
|---|---|
| `GET /health` (و `HEAD`) | وضعیت سرویس: uptime، ربات‌ها، وبهوک، پینگ، دیتابیس |
| `POST /webhook/game` | دریافت آپدیت‌های ربات بازی از تلگرام |
| `POST /webhook/admin` | دریافت آپدیت‌های ربات ادمین |
| `GET /webhook/info` | اطلاعات وبهوک هر دو ربات (`getWebhookInfo`) |
| `POST /webhook/set` | ثبت وبهوک روی `WEBHOOK_BASE_URL` |
| `POST /webhook/delete` | حذف وبهوک و بازگشت به polling |

اجرا:

```bash
python3 run_webhook.py                          # سرویس وبهوک + /health روی WEBHOOK_PORT (پیش‌فرض 8080)
python3 run_webhook.py --set-webhook https://my.app
python3 run_webhook.py --info
python3 run_webhook.py --delete-webhook
```

- 🔐 اگر `WEBHOOK_SECRET` تنظیم شود، هر درخواست باید هدر `X-Telegram-Bot-Api-Secret-Token` درست داشته باشد وگرنه `403` می‌گیرد.
- ♻️ در این حالت هوک‌های startup (زمان‌بند درآمد، رأی‌گیری و…) هم اجرا می‌شوند؛ یعنی همه‌چیز مثل polling کار می‌کند.
- 💓 **پینگ بیدارباش**: سرور پایتونی هر `KEEPALIVE_MINUTES` (پیش‌فرض **۱۰ دقیقه**) یک درخواست فیک به `${WEBAPP_URL یا آدرس عمومی}/health` می‌زند تا سرویس خواب نرود. وضعیتش در `/health` و `/api/keepalive` دیده می‌شود.
- 🎛 از پنل وب: `GET /api/keepalive`، `POST /api/keepalive/ping`، `POST /api/keepalive {enabled, intervalMinutes}`، `GET /api/webhook/status`، `POST /api/webhook/set {baseUrl}`، `POST /api/webhook/delete`، `POST /api/webhook/mode {mode:"webhook"|"polling", baseUrl}`.

### ☁️ میزبانی روی PythonAnywhere (وب‌هوک)
روی هاست‌های WSGI (مثل PythonAnywhere) نه polling ممکن است نه پروسهٔ دائمی؛ برای همین
`webapp/paw_wsgi.py` یک اپلیکیشن WSGI آماده است که آپدیت‌های تلگرام را مستقیم به
Dispatcher ها می‌دهد و کارهای دوره‌ای (درآمد، نفت، انقلاب، رأی‌گیری) را در هر درخواست
با محدودیت یک‌دقیقه‌ای اجرا می‌کند.

```bash
python3 paw_start.py --base-url https://USERNAME.pythonanywhere.com   # ثبت وبهوک + استارت
```

مسیرهای سرویس: `/health`، `/info`، `/setup`، `/panel`، `/webhook/game`، `/webhook/admin`.
راهنمای کامل: `../DEPLOY_PYTHONANYWHERE.md`.

### 🛡 امنیت (نسخهٔ ۱۰)

`worldwar-game/OWNER_SECURITY_REPORT.md`.

**کار فوری بعد از آپدیت:** توکن‌ها در `core/config.py` ثابت بوده‌اند؛ از @BotFather
Revoke کنید و توکن تازه بگذارید؛ بعد `🔐 امنیت` → `🧩 چرخاندن کلید وبهوک` و
`python3 paw_start.py --base-url https://arezog210.pythonanywhere.com`.

| لایه | چه چیزی بسته شد |
|---|---|
| 🧩 کلید وبهوک **اجباری** | بدون `WEBHOOK_SECRET` هیچ آپدیتی پذیرفته نمی‌شود؛ کلید در اولین اجرا خودکار ساخته و در دیتابیس (مخفی) ذخیره می‌شود؛ مقایسهٔ زمان‌ثابت؛ `/webhook/set` و `/webhook/delete` هم کلید می‌خواهند؛ آپدیت تکراری اجرا نمی‌شود؛ ۲۴۰ درخواست/دقیقه در هر IP |
| 🔐 پنل وب | `/login` + کوکی نشست امضاشده (۱۲ ساعته)؛ همهٔ `/api/*` بدون نشست → ۴۰۱؛ قفل ۸ تلاش در ۵ دقیقه + هشدار تلگرامی؛ مقدارهای محرمانه در نمای جدول `settings` پنهان؛ `/health` عمومی |
| 📣 پیام همگانی | فقط سوپرادمین + کد تأیید ۴رقمی یک‌بارمصرف + سقف ساعتی + قفل اضطراری + پاک‌سازی متن + لاگ در `security_events` و `admin_logs` |
| 🧩 یکپارچگی آپدیت | میدل‌ور `gamebot/middleware.py`: آپدیت از طرف ربات، تاریخ نامعتبر، یا گفتگوی خصوصی با `chat.id ≠ from.id` رد و ثبت می‌شود |
| 🖥 پنل امنیت | ربات ادمین و پنل بازی: `🔐 امنیت` — قفل/بازکردن همگانی، چرخش کلید وبهوک، گذرواژهٔ تازهٔ پنل، تست هشدار، رخدادها، تنظیمات (برچسب فارسی + راهنما) |
